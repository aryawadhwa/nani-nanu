# Anita & Vimal — 50th Golden Anniversary (Suvarna Mahotsav)

A mobile-first, cinematic digital invitation celebrating 50 Sacred Years of Anita & Vimal at **Sawarthia Sewa Sadan, Ayodhya Dham** (Sunday, December 27, 2026).

---

## ✨ Features & Design Highlights

- **Sacred Ayodhya Aesthetic**: Twilight plum (`#0c0813`), royal Kesariya saffron (`#e65100`), vibrant marigold gold (`#f59e0b`), and soft Chandan ivory typography (`#fcfbf7`).
- **Zero Raw Emojis**: 100% crisp inline vector SVG graphics for authentic luxury presentation.
- **Temple Bell Audio Synthesis**: Authentic brass temple bell (*ghantā*) synthesized via Web Audio API with zero audio file dependencies.
- **Floating River Diyas & Embers**: Lightweight HTML5 Canvas particle system simulating sacred river diyas floating on the Saryu River.
- **Live Countdown Timer**: Real-time days, hours, minutes, and seconds countdown to December 26, 2026.
- **Three-Day Itinerary Tabs**: Scannable schedule covering Welcome Luncheon, Sangeet, Wedding Ceremony, Gala Dinner, and Departures.
- **Ayodhya Winter Weather & Attire Advisory**: Daytime pleasant sun (21°C–23°C) and chilly night (8°C–10°C) with attire recommendations.
- **Venue & Navigation**: Address for Sawarthia Sewa Sadan, NH-27, Shahnewajpur Manjha, Ayodhya with 1-tap Google Maps directions and venue website links.
- **1-Tap WhatsApp RSVP**: Pre-formatted confirmation message ready to send with one tap.
- **Add to Calendar**: Exports `.ics` calendar events compatible with Apple Calendar, Google Calendar, and Outlook.
- **Digital Ashirwad & Blessings Wall**: Allows family and guests to post warm wishes for Anita & Vimal.

---

## 📱 Mobile-First Architecture

- Fluid `clamp()` typography and full viewport support (`100dvh`).
- Minimum 48px touch targets for comfortable one-handed phone use.
- iOS notch and home-indicator safe-area insets (`env(safe-area-inset-bottom)`).
- Sticky bottom navigation bar for quick one-thumb jumping to Schedule, Venue, Weather, RSVP, and Wishes.

## 🚀 Live Deployment via GitHub Pages

This repository is ready to be served directly with GitHub Pages:

1. In this repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch **`main`** and folder **`/ (root)`**, then click **Save**.
4. GitHub Pages will build and deploy your site to:
   `https://aryawadhwa.github.io/nani-nanu/`
